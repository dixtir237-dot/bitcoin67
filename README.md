# Bitcoin Clicker — Android APK через GitHub Actions

Это проект Android-приложения, которое открывает `app/src/main/assets/index.html` локально внутри Android WebView. HTML включён в APK, поэтому для самой игры сайт не нужен.

## Важно про офлайн-версию
- Онлайн-аккаунты, облачные сохранения, серверные объявления и мировой рейтинг отключены.
- Из HTML удалены реальные URL/ID/ключ базы данных и встроенный хеш администратора.
- Прогресс игры сохраняется локально через `localStorage` на устройстве.
- Внешний Google Fonts отключён, чтобы игра не зависела от сети для шрифта.

## Собрать APK через GitHub (с телефона тоже можно)

1. Распакуйте ZIP.
2. Откройте https://github.com/ и войдите.
3. Нажмите **New repository**, задайте имя, например `bitcoin-clicker-android`, и создайте репозиторий.
4. Загрузите **содержимое распакованной папки** в репозиторий (папки `.github`, `app` и файлы `build.gradle`, `settings.gradle`, `gradle.properties` должны оказаться в корне репозитория).
   - В веб-интерфейсе GitHub можно нажать **Add file → Upload files**.
   - Убедитесь, что папка `.github/workflows` тоже загружена. Если мобильный интерфейс не позволяет загрузить скрытую папку, используйте GitHub Desktop или загрузку через git с компьютера.
5. Откройте вкладку **Actions** репозитория. Если GitHub попросит разрешить запуск workflows, нажмите разрешение.
6. Выберите **Build Bitcoin Clicker APK** и нажмите **Run workflow**. Сборка также запускается при push в `main` или `master`.
7. Дождитесь зелёной галочки у workflow. Откройте завершённый запуск, прокрутите до **Artifacts** и скачайте `Bitcoin-Clicker-APK`.
8. Распакуйте скачанный artifact ZIP. Внутри будет `app-debug.apk`.
9. Откройте APK на Android и разрешите установку из этого источника, если телефон спросит.

## Что получится
- Название приложения: Bitcoin Clicker
- Package ID: `com.bitcoinclicker.app`
- Debug APK (для личной установки и тестирования; не подписан для публикации в Google Play)

## Если сборка не запускается
- Проверьте, что файлы лежат в корне репозитория, а не в дополнительной вложенной папке.
- Убедитесь, что workflow находится по пути `.github/workflows/build-apk.yml`.
- Откройте **Actions → последний запуск → Build debug APK**, чтобы увидеть лог ошибки.

## Секреты
Не добавляйте API-ключи, пароли или admin-хеши в публичный репозиторий. Этот проект специально отключает онлайн API и не включает исходные ключи.
